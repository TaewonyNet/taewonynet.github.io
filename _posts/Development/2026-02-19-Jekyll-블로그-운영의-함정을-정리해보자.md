## Jekyll 블로그 운영의 함정을 정리해보자
Chirpy 테마로 블로그를 운영하며 만난 숫자 태그 YAML 함정과 Dependabot 의존성 관리를 정리해보자.

### 1. 서론 (Introduction)
- **문제/상황 (Problem):** 회고 글에 `tags: [2026, 1]`처럼 연도·월을 태그로 달았더니 태그 페이지가 깨지고 빌드가 어긋났다. 동시에 Dependabot이 워크플로 의존성 PR을 흩어서 쏟아내 원인 추적이 번거로웠다.
- **목적 (Purpose):** 재발하는 두 운영 함정을 한 번에 정리해 다음 글부터는 같은 실수를 반복하지 않는다.
- **대상 (Target Audience):** Jekyll(특히 Chirpy)로 GitHub Pages 블로그를 직접 운영하는 개발자

### 2. 방법 및 과정 (Methods & Process)
- **배경 조사 및 데이터 (Data Collection):**
    - frontmatter는 YAML이므로 따옴표 없는 `2026`은 *문자열이 아니라 정수*로 파싱된다. Chirpy의 태그·카테고리 로직은 문자열을 전제하므로 정수 태그가 링크·페이지 생성에서 어긋난다.
    - 실제 발행본(`2026-02-03-2026년-1월-회고.md`)의 정상 사례: `tags: [회고, '2026', '1']` — 숫자를 항상 문자열로 따옴표 처리한다.
    - Dependabot은 기본 설정이면 워크플로 파일마다 개별 PR을 만들어, 여러 의존성이 한 번에 바뀌면 어떤 변경이 원인인지 추적하기 어렵다.
- **접근 방법 (Approach Methods):**
    - **[방법 1]:** 숫자로만 된 태그·카테고리는 *반드시 따옴표로 감싼다.* 사람이 매번 기억하기보다 기계적으로 검사한다.
    - **[방법 2]:** Dependabot 업데이트를 *그룹으로 묶어* PR 수를 줄이고, 정기적으로 일괄 검토·머지한다.
- **분석 및 해결 프로세스 (Analysis Flow):**
    - **도구/기술:** Jekyll, Chirpy, GitHub Pages, Dependabot, Python(정규식 기반 frontmatter 린터)
    - **주요 단계:** frontmatter 텍스트 스캔 $\rightarrow$ `tags`/`categories` 안 따옴표 없는 순수 숫자 항목 탐지 $\rightarrow$ `--fix`로 자동 따옴표 처리 $\rightarrow$ Dependabot 그룹화로 PR 수 감소
    - **결과 도출 및 검증:** 린터로 기존 회고 글을 스캔해 따옴표 없는 숫자 태그를 전수 확인하고, `--fix` 적용 후 태그 페이지가 정상 생성됨을 확인한다.

### 3. 결과 (Results)
- **분석 결과 요약:** 숫자 태그 따옴표 규칙을 세운 뒤 빌드·태그 페이지 오류가 사라졌다. Dependabot을 dev-deps·prod-deps·gh-actions 그룹으로 묶으니 매주 흩어지던 PR이 그룹당 한 건으로 줄었다.

### 4. 인사이트 및 액션 (Insights & Action)
- **인사이트 (Insight):** frontmatter는 결국 YAML이다. 타입을 의식하지 않으면 *조용히* 어긋난다. 사람이 매번 확인하는 대신 기계적 검사로 옮기면 재발이 없다.
- **실행 방안 (Action Plan):** 글 템플릿의 태그 예시를 처음부터 따옴표 형태로 둬서 실수를 원천 차단하고, 발행 전 린터를 한 번 돌린다.
- **한 줄 결론 (Key Takeaway):** 숫자 태그는 무조건 따옴표로 감싸고, 의존성은 그룹으로 묶어 관리하자. [샘플 코드](https://github.com/TaewonyNet/taewonynet.github.io/blob/master/src/jekyll_frontmatter_lint.py){: target="_blank"}
- **다음 스텝 (Next Step):** 지금 린터는 `tags`/`categories`의 순수 숫자 항목만 잡는다. `date`나 다른 frontmatter 필드의 타입 오류(예: 시간대 누락)까지 넓히면 발행 전 자동 검사 범위가 더 촘촘해진다.
